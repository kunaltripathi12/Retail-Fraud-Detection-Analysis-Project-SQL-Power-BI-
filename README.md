# Retail-Fraud-Detection-Analysis-Project-SQL-Power-BI-
This project analyzes 100,000+ retail transactions to identify fraudulent activities, high-risk customers, and suspicious transaction patterns using SQL and Power BI.  The objective is to transform raw transaction data into actionable insights that help businesses reduce fraud exposure and improve transaction monitoring.

Key Insights
High transaction velocity is strongly associated with fraud.
International transactions show elevated fraud risk.
Customers with previous fraud history are more likely to perform fraudulent transactions.
Certain merchant categories exhibit higher fraud rates.
